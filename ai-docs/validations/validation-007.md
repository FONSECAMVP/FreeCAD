## Check 3 — Decision-implementation alignment: FAIL

**Drift 1 — DES-005 §A2-S2 "Busy guard" no longer wired.**

`design.md:146`:
> **Busy guard (A2-S2):** Panel sets `_busy = True` when connected to FreeCADGui workbench-switch and document-load signals. `dispatch()` returns `{"error": "busy"}` if `_busy` is True, preventing FreeCAD API calls during unsafe transitions.

Current `panel.py`:
- `_set_busy()` only touches UI widgets (send button, input, thinking label).
- `_connect_freecad_events` connects `workbenchActivated` to `lambda _: self._executor.set_busy(False)` — sets to False, never True.
- No connection to a document-load signal at all.

Net: `executor._busy` is effectively only ever `False`. The A2-S2 guard described in DES-005 is not implemented. The recent diff makes the omission explicit (and gives a sound reason: the previous wiring self-blocked the worker's own dispatch). But the documented mitigation is gone, and no DEC supersedes it.

The new `self.form` + `__init__(_parent=None)` matches the standard FreeCAD prefs widget pattern (AddonManager/AddonManagerOptions.py is cited inline). No contradiction with DES-006; the idiom change is consistent with DEC-006 storage roles. **No drift here** — listed for completeness.
